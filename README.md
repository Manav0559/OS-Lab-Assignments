# OS Lab Assignments

Manav Singla, 2402MC02. Operating Systems lab work on xv6 (RISC-V for 5-7, x86 for 8-9).

| Folder | Topic |
|---|---|
| [Assignment_05](Assignment_05) | Process synchronization: Peterson, Producer-Consumer, Readers-Writers, Dining Philosophers |
| [Assignment_06](Assignment_06) | Deadlocks: Banker's algorithm, RAG cycle detection, resource ordering |
| [Assignment_07](Assignment_07) | Threads (clone/join), semaphores, deadlock detection, priority scheduling with aging |
| [Assignment_08](Assignment_08) | Memory management on xv6 x86: va2pa, getmeminfo, vmprint, lazy heap allocation |
| [Assignment_09](Assignment_09) | Page table printing, lazy allocation with fault counting, FIFO vs LRU page replacement (xv6 x86) |

Each folder has its own README with build and run steps.
